# Finance-and-Loan-Management
Finance & Loan Enquiry Management System

It is a desktop-based Java application for a finance company to manage customer enquiries and records.

What it does
👤 Collects customer details
💰 Handles finance/loan enquiries
📝 Adds new enquiries
🗑️ Deletes enquiries
📋 Manages customer records
🗄️ Stores/connects data with MySQL
🖥️ Uses Java Swing for the user interface

The main screen specifically identifies the application as “MAVKAR FINANCE” and provides options such as Add Enquiry, Delete Enquiry, Update Record, Display All, and Loan Services.

For your resume, you can categorize it as:

Project Domain: Finance / Banking
Project Type: Desktop Application
Technology: Java Swing + JDBC + MySQL
Main Concept: CRUD & Database Management
